# 🎨 域灵设计系统 (szyg Design System)

> 本目录存放域灵系统的全局体验设计规范。所有前端实现必须遵循本目录定义的视觉语言、布局框架与组件形态。
> 本设计系统的核心哲学是 **Effie Aesthetic**：极致简约、温润克制、让内容成为主角。

## 设计哲学

1. **退让 (Retreat)**：UI 框架（侧边栏、顶栏）必须存在感极低，像纸的装订线。
2. **呼吸 (Breath)**： generous whitespace 是主要的信息组织手段，而不是边框或色块。
3. **克制 (Restraint)**：颜色、阴影、动效只做必要表达，避免装饰性元素。
4. **温润 (Warmth)**：背景、文字、交互都使用暖调，避免冷硬的科技灰。
5. **专注 (Focus)**：减少视觉噪音，让用户始终处于沉浸式工作状态。
6. **和谐 (Harmony)**： typography、spacing、radius、motion 基于统一的比例系统（4px 网格 + 黄金比例）。

## 范围边界

- 覆盖：`web/src/` 下所有 Vue 页面、组件、样式文件。
- 覆盖：Element Plus 组件的二次封装与全局覆盖。
- 不覆盖：业务逻辑、数据流、API 调用。
- 与现有 `@d:|\szyg\web\src\style.css` 和 `@d:\szyg\web\src\tech-theme.css` 的关系：现有文件为历史实现，本规范为权威目标态，迁移计划将逐步替换旧变量与覆盖样式。

## 变更流程

任何对设计系统的修改，必须先更新本目录文档，再改动代码。修改需说明：变更原因、影响范围、验收标准。
