# 🏗️ 应用外壳与布局框架

> 本文件为旧版Vue布局框架的架构参考。
> **实际前端布局以 `szyg-frontend/src/components/Layout.tsx` 为准**。

## 实际布局结构

```
┌────────────────────────────────────────────────────┐
│  Sidebar (260px)  │  TopBar (64px)                 │
│                   ├────────────────────────────────┤
│  Logo / 导航       │  Page Content (pt-8 px-8)       │
│                    │                                │
│  ◀ 折叠 (72px)    │                                │
└──────────────────┴────────────────────────────────┘
```

## 布局关键参数

| 区域 | 展开 | 折叠 | 背景 |
|------|------|------|------|
| Sidebar | 260px | 72px | bg-[#111827] |
| TopBar | 64px | 64px | bg-[#111827] |
| Content | flex-1 | flex-1 | bg-[#0B0F1A] |

## 实现文件

| 文件 | 职责 |
|------|------|
| `Layout.tsx` | 布局容器 (Sidebar + TopBar + Content) |
| `Sidebar.tsx` | 侧边栏导航 (展开/折叠/高亮) |
| `TopBar.tsx` | 顶部栏 (标题/搜索/主题/用户) |
| `Footer.tsx` | 页脚 (底部信息) |
