## 1. 设计目标

AI视频工作台是面向中小企业运营人员的**一站式视频生产空间**。用户在同一个页面内完成从创意到发布的完整链路：

```
创作 → 粗剪 → 精修 → 预览 → 发布
```

与超级员工的区别：超级员工是「对话驱动一切」的通用入口；AI视频是垂直领域工作站，减少对话回合，提升视频生产效率。

## 3. 左栏 — 工具箱

### 3.1 AI生视频入口

| 属性 | 值 |
|------|-----|
| 位置 | 工具箱顶部 |
| 内容 | 大号按钮 + 提示词输入框 |
| 交互 | 点击弹出创作Dialog / 直接输入 + 快捷风格标签 |

**创作Dialog**：
```
┌─────────────────────────────────┐
│  AI 生成视频                     │
│                                 │
│  [文本输入框，自动变高]           │
│  "描述你想要的视频内容..."        │
│                                 │
│  时长: [5s ▾]  风格: [写实 ▾]    │
│  模式: [文生视频 ▾] 模型: [豆包]  │
│                                 │
│  快捷风格标签:                    │
│  [写实] [动漫] [电影感] [赛博朋克] │
│                                 │
│  [取消]              [🔥 开始生成] │
└─────────────────────────────────┘
```

**参数**：
| 参数 | 可选值 | 默认 |
|------|--------|------|
| 文本 | 自然语言描述 | — |
| 时长 | 3s / 5s / 10s / 15s | 5s |
| 风格 | realistic / anime / cinematic / cyberpunk | realistic |
| 模式 | 文生视频 / 图生视频(需上传参考图) | 文生视频 |
| 模型 | doubao-video / Seaweed | doubao-video |

### 3.2 本地上传

| 属性 | 值 |
|------|-----|
| 位置 | AI生视频按钮下方 |
| 内容 | 「+ 上传视频」按钮 + 拖拽区 |
| 支持格式 | .mp4 .mov .avi .mkv |
| 最大文件 | 500MB（可配置） |
| 上传后行为 | 自动添加到右栏素材库 + 在预览区播放 |

### 3.3 剪辑工具列表

| 工具 | 图标 | 操作方式 | 后端工具 |
|------|------|----------|----------|
| 裁剪 | ✂️ | 拖动时间轴选取起止点 + 输入秒数 | video_cut |
| 拼接 | 🔗 | 从素材库拖入多个视频，排序 | video_concat |
| 变速 | ⏱ | 滑块 0.25x~4x | video_speed |
| 添加标题 | T | 文本输入 + 字号/颜色/位置选择 | video_add_title |
| 混音 | 🎵 | 原声音量滑块 + BGM素材选择 | video_mix_audio |
| 提取封面 | 🖼 | 时间点输入 + 尺寸选择 | video_extract_frame |
| 模板 | 🎞 | 模板列表选择→参数填写 | video_templates → video_render |

**剪辑交互模式**：
- 点击工具 → 展开操作面板（内含参数输入+「应用」按钮）
- 应用后 → 后端执行 → 预览区刷新为新视频
- 支持撤销（保留原始文件）
- 链式操作：「裁剪 + 标题 + 混音」可一次性提交

**链式操作面板**：
```
┌─────────────────────────┐
│  剪辑操作链              │
│                         │
│  [✂️ 裁剪: 0s~10s]  [×]│
│  [T  标题: 新品上市] [×]│
│  [🎵 混音: bgm.mp3]  [×]│
│  [+ 添加步骤]            │
│                         │
│  [🔄 应用全部] [🗑 清空] │
│                         │
│  操作链预览:              │
│  原始(30s) → 裁剪(0-10s) │
│  → 叠加标题 → 混音       │
│  → 预期输出: 约10s        │
└─────────────────────────┘
```

### 3.4 发布入口

| 属性 | 值 |
|------|-----|
| 位置 | 工具箱底部 |
| 内容 | 「🚀 一键发布」按钮 |
| 点击后 | 弹出发布面板 → 选择平台(抖音/小红书/B站/快手/微信) → 填写标题+标签+描述 → 即时/定时 |

## 4. 中栏 — 预览区 + 对话区

### 4.1 预览区（上半部分）

两种状态：生成中(进度卡片) / 完成(视频播放器)

**生成中状态**：参照 `ARCHITECTURE/specs/chat-video-card.md` 的进度卡片设计：
```

│  ⏳ 「海浪拍打岩石的慢镜头」        │
│  状态: 生成中 65%                   │
│  ████████████░░░░░░░░  65%         │
│                                    │
│  [取消生成]                        │
└────────────────────────────────────┘
```

**完成状态**：
```

│  ┌──────────────────────────────┐  │
│  │                              │  │
│  │     <video> 播放器           │  │

│  │                              │  │

│                                    │
│  [🔍 放大] [⛶ 全屏] [⬇ 下载]     │
│  [✂️ 裁剪] [📤 发布]              │
└────────────────────────────────────┘
```

### 4.2 对话消息流（下半部分）

与超级员工相同的SSE消息流，但位于预览区下方，高度可调整：
- 发送「给当前视频加上标题xxxx」→ AI调用video_add_title
- 发送「把音量调低30%」→ AI调用video_mix_audio
- 发送「用模板1渲染」→ AI调用video_render

消息类型：(text/tool_call/tool_result/image/video)
视频消息中「当前视频」自动替换预览区内容。

### 4.3 输入框

- 自动解析目标：「当前视频」指预览区正在播放的视频
- 支持 @提及素材 @素材名
- placeholder: "输入剪辑指令，或描述要生成的视频..."
- 快捷指令标签：[裁剪前10秒] [加背景音乐] [叠加标题] [导出封面]

## 7. 数据流与API对接

### 7.1 视频生成流程

```
用户在AI视频页触发生成
  → POST /api/hermes/chat (SSE)   ← 复用Hermes对话引擎
    → LLM调用 ai_video_create(tool)
      → SSE: video_task 事件
    → LLM轮询 ai_video_task_status
      → SSE: video_status 事件 (进度更新)
    → 生成完成
      → SSE: video 事件 (video_url)
  → 视频出现在预览区 + 自动存入右栏视频库
  → 对话保存 (与超级员工共享同一conversation接口)
```

### 7.2 剪辑操作流程

```
用户在预览区调剪辑工具
  → 直接调用对应后端API（非SSE），更快
    POST /api/video/cut    {path, start, duration}
    POST /api/video/speed  {path, speed}
    POST /api/video/title  {path, title, font_size, color}
    ...
  → 返回 {ok: true, output_path}
  → 预览区刷新为新视频路径

若通过对话命令（SSE）:
  → POST /api/hermes/chat
    → LLM调用对应video_* tool
    → SSE: tool_call → tool_result
    → 前端识别video相关tool_result → 更新预览区
```

### 7.3 API清单

| API | 方法 | 用途 |
|-----|------|------|
| `/api/video/create` | POST | AI文生/图生视频（异步） |
| `/api/video/status/{task_id}` | GET | 查询视频生成任务状态 |
| `/api/video/cut` | POST | 裁剪 |
| `/api/video/concat` | POST | 拼接 |
| `/api/video/speed` | POST | 变速 |
| `/api/video/title` | POST | 叠加标题 |
| `/api/video/audio-mix` | POST | 混音 |
| `/api/video/extract-frame` | POST | 提取封面帧 |
| `/api/video/templates` | GET | 模板列表 |
| `/api/video/render` | POST | 模板渲染 |
| `/api/video/upload` | POST | 本地上传 |
| `/api/video/library` | GET | 视频库列表(带筛选) |
| `/api/video/{id}` | DELETE | 删除视频 |
| `/api/publisher/publish` | POST | 发布视频到平台 |

> 注：其中大部分API已存在(video_cut_engine.py + hermes_chat tools)，需在video_endpoint.py中补充REST风格封装

## 8. 状态管理

### 8.1 页面状态机

```
视频页状态:
  idle           → 未选择视频,显示空状态(上传引导 + 生成入口)
  generating     → 视频生成中,显示进度卡片
  previewing     → 视频预览,显示播放器 + 工具链可用
  editing        → 剪辑操作中,工具参数面板展开
  publishing     → 发布弹窗打开
  error          → 生成/剪辑失败,显示错误提示+重试
```

## 10. 验收标准

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | AI生成视频 | 输入描述→进度卡片→播放器，全流程 < 5分钟 |
| 2 | 本地上传 | 拖拽/点击上传→预览区播放→存入视频库 |
| 3 | 裁剪操作 | 设置起止时间→预览区刷新为新视频 |
| 4 | 拼接操作 | 从视频库拖入多个→预览区播放拼接结果 |
| 5 | 变速操作 | 滑块调节→预览区播放变速结果 |
| 6 | 标题叠加 | 输入文字→设置字号颜色→标题出现在视频上 |
| 7 | 混音操作 | 选择BGM→原声+BGM共存 |
| 8 | 提取封面 | 指定时间点→下载封面图片 |
| 9 | 模板渲染 | 选择模板→填写参数→预览→生成 |
| 10 | 操作链 | 多项操作排队→一次性提交→预览最终结果 |
| 11 | 视频库 | AI生成+上传视频在网格展示，支持预览/下载/删除 |
| 12 | 发布 | 选择平台→填写title/tags→即时/定时发送 |
| 13 | 深色风格 | 全页面遵循 szyg-frontend/DESIGN_SYSTEM.md |
| 14 | 构建通过 | npm run build 无错误 |
| 15 | 响应式 | 4个断点下布局正常 |
