# 🎯 域灵系统 — 功能模块树设计 (v1.0)

> 版本：v1.0
> 日期：2026-07-05
> 状态：确定并交付实施
> 前端：React 19 + TypeScript + Vite + Tailwind CSS
> 后端：Python 3.12 + FastAPI

---

## 设计原则

1. **金字塔收敛**：所有功能最终通过「AI员工→超级员工」对话驱动
2. **模块自治**：每个一级模块有独立的Shell和路由空间
3. **渐进式填充**：先搭骨架(侧边栏导航+路由)，再逐个页面填内容
4. **一级模块 ≤ 9个**：侧边栏空间有限，超过则需要精简或合并

## 分阶段实施路线

### Phase A — 骨架搭建 (当前Phase 1核心任务)

```
步骤1: 建立路由树
  ├─ router.tsx/App.tsx 中定义全部9个一级路由+二级路由
  ├─ 创建 Shell 页面 (Layout-based pages with Sidebar+TopBar)
  └─ 设置向后兼容重定向

步骤2: 侧边栏导航实现
  ├─ Sidebar.tsx 菜单数据从API动态加载(或静态配置)
  ├─ 展开/折叠逻辑
  ├─ 二级菜单缩进与展开
  └─ 当前路由高亮

步骤3: 二级路由页面占位
  ├─ 每个二级页面创建 .tsx 占位组件
  ├─ 内容为模块标题+「开发中」提示+空状态
  └─ 确保路由跳转无404
```

### Phase B — 功能填充 (测试通过一个填充一个)

```
P0: 完善超级员工对话页面
  ├─ SSE流式对接后端 /api/hermes/chat
  ├─ 对话历史CRUD对接 /api/conversations
  ├─ 视频/图片卡片渲染
  └─ 工具调用可视化

P1: AI人才市场
  ├─ Agency 232个专家数据接入
  ├─ 分类/搜索/详情页
  └─ 「使用此专家」→ Hermes切换System Prompt

P1: AI视频工作台
  ├─ 对话驱动的视频生成
  ├─ 视频剪辑工具
  └─ 视频资产管理

P1: 发布中心+账号管理
  ├─ 平台状态可视化
  ├─ 扫码登录交互
  └─ 发布表单+结果展示

P1: 智能截流+舆情监听
  ├─ 搜索策略配置
  ├─ 监听面板
  └─ 执行结果流
```

### Phase C — 增强完善 (P2)


## 关键设计决策

| 决策 | 理由 |
|------|------|
| 首页=超级员工 | 唯一核心交互入口，90%用户时间在此 |
| AI视频归入AI员工 | 视频是AI能力，通过对话驱动 |
| AI人才市场归入AI员工 | 专家选择是「当前角色」切换 |
| 发布管理独立一级 | 发布是独立链路(登录→选平台→发布→查数据) |
| 营销获客聚焦4个子模块 | 企业获客/到店引流/A-B测试→归入或暂缓 |
| 保留向后兼容重定向 | 确保旧链接不404 |
