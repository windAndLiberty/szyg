# 📄 PRD: AI 数字员工 / 智能体系统

> 本文件定义域灵系统中 AI 数字员工（超级员工）的产品需求。
> 页面级设计规范见 `KnowledgeBase/DESIGN/page-super-agent.md`。

---

## 1. 业务背景

域灵系统需要一个人机交互工作台，让非技术用户通过自然语言指挥 AI 员工完成多平台内容营销任务（搜索、生成、发布、截流、接待等）。该工作台是系统的核心入口，定位为"一句话指挥 AI 干活"。

## 2. 用户故事

- 作为运营人员，我希望通过对话历史快速找到之前的任务记录。
- 作为运营人员，我希望在新建对话时看到引导提示和快捷操作，降低使用门槛。
- 作为运营人员，我希望看到 AI 的执行过程（工具调用），了解任务进展。
- 作为运营人员，我希望对话界面沉浸、无干扰，专注于任务对话本身。

## 3. 功能清单

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 对话历史面板 | 展示历史对话列表，支持选择/新建 | P0 |
| 对话区域 | 消息展示（Markdown + 工具调用） | P0 |
| 欢迎引导空状态 | 无对话时显示 Agent 介绍 + 快捷操作卡片 | P0 |
| 快捷标签栏 | 输入区上方显示常用指令标签，点击填入 | P1 |
| 流式输出 | AI 回复实时流式渲染 | P0 |
| 对话保存 | 自动保存对话到后端 | P1 |
| 快捷卡片自动发送 | 点击快捷卡片直接发送指令 | P1 |

## 4. 非功能需求

- 对话历史面板需占满应用外壳的上下左边界（full-bleed），不受全局内容区 padding 影响。
- 欢迎空状态在无消息时居中显示，包含 Agent 图标、欢迎语、快捷卡片网格。
- 页面在 1280px / 1024px / 768px / 480px 断点下布局正常。
- 流式输出延迟不超过 500ms 首字。
- 所有 UI 遵循 `KnowledgeBase/DESIGN/design-system.md` 全局设计系统。

## 5. 验收标准

- [ ] 对话历史面板紧贴 App Sidebar 右侧，从顶栏底部延伸到视口底部，无额外 padding。
- [ ] 新建对话时，Chat Area 中间显示欢迎空状态（Agent 图标 + 标题 + 描述 + 快捷卡片）。
- [ ] 点击快捷卡片后自动发送指令，进入对话。
- [ ] 点击快捷标签仅填入输入框，不自动发送。
- [ ] 流式输出正常，工具调用标签实时更新状态。
- [ ] 对话历史可正常加载、选择、切换。
- [ ] Light / Dark 模式下视觉一致。
