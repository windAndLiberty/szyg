# ⚠️ 全局错误码定义

## HTTP 状态码使用

| 状态码 | 含义 | 使用场景 |
|--------|------|----------|
| 200 | OK | 成功获取/操作资源 |
| 201 | Created | 成功创建资源 |
| 400 | Bad Request | 请求参数错误/格式不对 |
| 401 | Unauthorized | 未登录/Token 过期 |
| 403 | Forbidden | 权限不足 (非 admin 访问 admin 接口) |
| 404 | Not Found | 资源不存在 |
| 409 | Conflict | 资源冲突 (如用户名已存在) |
| 422 | Unprocessable Entity | 请求体校验失败 (Pydantic ValidationError) |
| 500 | Internal Server Error | 服务器内部异常 |

## 业务错误约定

- 错误信息通过 `detail` 字段返回
- 中文错误信息面向终端用户
- 英文错误信息面向开发者 (日志中记录)

## 常见错误场景

| 场景 | 状态码 | detail 示例 |
|------|--------|-------------|
| 用户名或密码错误 | 401 | `"用户名或密码错误"` |
| 用户名已存在 | 409 | `"用户名已存在"` |
| 平台未登录 | 400 | `"平台账号未绑定"` |
| 文件不存在 | 404 | `"文件不存在: {path}"` |
| LLM 后端不可用 | 503 | `"LLM 后端不可用"` |
