# LLM 工具输出与回复规范

> 本文件定义 Hermes Chat 中 LLM 如何处理工具返回数据并向用户呈现结果的规范。
> 涉及源码：`server/szyg/api/hermes_chat.py` → `SYSTEM_PROMPT` 及 tool result 处理逻辑。

---

## 1. 问题描述

当前 LLM 在调用工具（如 `acq_search`）后，会先输出一段格式化的自然语言总结（正确），紧接着又把工具返回的原始 JSON 字符串原样输出给用户（错误）。导致用户看到重复、混乱的回复。

## 2. 根因

- `SYSTEM_PROMPT` 末尾的回复要求过于简短（仅一句"用简体中文，简洁专业"），未明确约束工具返回数据的呈现方式。
- LLM 不清楚工具返回的 JSON 是"供参考的上下文数据"还是"需要转述给用户的内容"。

## 3. System Prompt 回复规范（需追加到 `SYSTEM_PROMPT`）

在 `hermes_chat.py` 的 `SYSTEM_PROMPT` 变量末尾，`## 回复要求` 章节中追加以下规则：

```
## 回复要求

用简体中文，简洁专业。函数调用的参数要准确填写。

### 工具结果呈现规则（必须严格遵守）
1. **禁止原样输出工具返回的 JSON**。工具返回的数据是供你分析和总结的内部数据，不是给用户看的原始内容。
2. 调用工具后，你必须用**自然语言 + 结构化格式**（如表格、列表）向用户总结工具结果的关键信息。
3. 如果工具返回的是列表数据（如搜索结果、评论列表），提取关键字段以表格或编号列表呈现，每条包含：标题/作者/互动数据/链接。
4. 如果工具返回的是操作结果（如发布成功、评论已发送），用一句话确认结果，附上关键标识（如帖子ID、链接）。
5. 如果工具返回错误，用自然语言解释失败原因和可能的解决方案，不要输出原始 error JSON。
6. **绝对不要**在回复中包含 `{"keyword": ...}`、`{"platform": ...}` 等原始 JSON 片段。
```

## 4. 各工具类型的输出模板

### 4.1 搜索类工具（`acq_search`、`acquisition_search`）

**工具返回**：`{"platform": "douyin", "keyword": "巨型犬", "total": 9, "videos": [{...}, ...]}`

**正确输出格式**：
```
为你找到抖音上关于"巨型犬"的9条相关视频：

| 序号 | 标题 | 作者 | 点赞数 | 链接 |
|------|------|------|--------|------|
| 1 | 土豪专属的烈性猛犬 | 赵姗 | 13034 | [点击查看](url) |
| 2 | ... | ... | ... | ... |

是否需要对这些视频进行截流操作？
```

**禁止输出**：`{"keyword": "巨型犬", "total": 9, "targets": [{"video_id": "7603...", ...}]}`

### 4.2 操作类工具（`platform_publish_direct`、`acq_send_comment`）

**工具返回**：`{"ok": true, "post_id": "xxx", "url": "..."}`

**正确输出格式**：
```
已成功发布到抖音！帖子ID: xxx，链接: https://...
```

### 4.3 状态类工具（`platform_status`、`brain_status`）

**工具返回**：`{"platform": "douyin", "is_logged_in": true, "account_name": "xxx"}`

**正确输出格式**：
```
抖音当前状态：已登录，账号: xxx
```

### 4.4 错误类

**工具返回**：`{"error": "搜索失败: timeout"}`

**正确输出格式**：
```
搜索失败，可能是网络超时。请稍后重试，或换个关键词再试。
```

## 5. 实现指引

### 5.1 System Prompt 修改

文件：`server/szyg/api/hermes_chat.py`
位置：`SYSTEM_PROMPT` 变量（约第 440 行），将现有的：
```python
## 回复要求
用简体中文，简洁专业。函数调用的参数要准确填写。"""
```
替换为：
```python
## 回复要求
用简体中文，简洁专业。函数调用的参数要准确填写。

### 工具结果呈现规则（必须严格遵守）
1. 禁止原样输出工具返回的 JSON。工具返回的数据是供你分析的内部数据，不是给用户看的原始内容。
2. 调用工具后，用自然语言 + 结构化格式（表格、列表）向用户总结关键信息。
3. 列表数据（搜索结果、评论列表）提取关键字段以表格或编号列表呈现。
4. 操作结果用一句话确认，附上关键标识。
5. 错误用自然语言解释原因和解决方案，不输出原始 error JSON。
6. 绝对不要在回复中包含原始 JSON 片段。"""
```

### 5.2 验收标准

- [ ] 搜索后只输出格式化的表格/列表，不输出原始 JSON
- [ ] 操作类工具只输出一句话确认 + 关键标识
- [ ] 错误类工具只输出自然语言解释
- [ ] 多轮对话中不出现任何 `{"keyword": ...}`、`{"platform": ...}` 等 JSON 片段
