# szyg 智能矩阵运营系统 — 需求文档

> 版本: 1.0 | 2026-06

---

## 一、系统概述

### 1.1 产品定位

szyg 是一个**自托管的 AI 营销超级员工系统**，面向中小企业提供从获客到成交的完整销售链路自动化。系统以 Hermes Agent 为 AI 内核，通过 24 个业务工具覆盖内容发布、线索管理、客户触达、话术生成、定时调度等核心场景。

### 1.2 核心卖点

| 卖点 | 说明 |
|------|------|
| **自托管** | 数据完全留存在企业自有环境，无第三方泄露风险 |
| **AI 超级员工** | 一个自然语言界面，调度全部 24 个工具自动完成任务 |
| **多模型** | 火山引擎驱动，DeepSeek V4 Pro/Flash 双模型，50 万 tokens/天免费额度 |
| **开箱即用** | 6 套行业话术模板、12 个 AI 智能体预设、8 个工具市场应用 |
| **开源 (MIT)** | 源码透明，可自由定制和二次开发 |

### 1.3 目标用户

| 角色 | 典型场景 |
|------|----------|
| **中小企业主** | 日常运营管理、营销决策、客户跟进 |
| **销售/运营人员** | 线索管理、话术生成、内容发布、定时任务 |
| **市场/新媒体运营** | 短视频内容创作、多平台分发、评论互动 |
| **代理商/OEM 客户** | 贴牌定制、子账号管理、多租户运营 |

## 二、功能模块

### 2.1 AI 超级员工

**一句话描述**: 用对话完成一切业务操作。

**能力范围**:
- 📊 线索查询与分析
- 💬 销冠话术生成
- 📝 内容创建与审核
- ⚡ 定时任务调度
- 🤖 AI 智能体调度
- 📚 知识库检索
- 🎨 品牌配置管理

**使用方式**: 打开「AI 超级员工」，用自然语言描述需求即可。例如：
- "搜索所有高意向线索，为每个生成一条跟进话术"
- "帮我创建一篇关于新品发布的推广文章，发布到抖音和小红书"
- "每天早上 9 点检查超过 3 天未回复的线索"

### 2.2 线索管家 (Lead Manager)

**功能**: 客户线索的发现、评分、管理、跟进全流程。

| 功能 | 描述 |
|------|------|
| **AI 意向评分** | 输入用户评论/消息内容，AI 自动判断购买意向等级（高/中/低/冷） |
| **线索搜索** | FTS5 全文搜索引擎，按意向等级、阶段、平台多维筛选 |
| **线索详情** | 查看客户画像、互动历史、推荐行动 |
| **智能建议** | AI 根据线索画像自动给出下一步跟进建议 |
| **自动评分** | 对接智能评论引擎，高意向互动自动创建线索 |

**意向等级说明**:
- 🔥 高意向：问了价格、购买方式、要联系方式 → 立即跟进
- 🔶 中意向：表达了兴趣、收藏 → 3 天内跟进
- 🔹 低意向：点赞、简单好评 → 定期维护
- ❄️ 冷线索：仅关注、无互动 → 培育型

### 2.3 销冠话术库 (Sales Scripts)

**功能**: 行业级话术模板管理与 AI 个性化生成。

| 功能 | 描述 |
|------|------|
| **行业模板** | 零售、B2B、本地服务、教育、健康 5 大行业，6 套话术模板 |
| **场景适配** | 价格咨询、质量疑虑、合作接洽、服务预约、课程咨询、健康咨询 |
| **AI 生成** | 根据行业、场景、产品信息自动填充话术 |
| **话术步骤** | 每套模板包含完整的销售步骤链：开场→价值→价格→CTA |
| **销售技巧** | 每套模板附带实战 tips |

### 2.4 内容发布 (Publisher)

**功能**: 多平台内容从创建到发布的全流程管理。

| 功能 | 描述 |
|------|------|
| **内容创建** | 支持短帖、长文、视频脚本、图文 4 种类型 |
| **AI 辅助创作** | 输入主题自动生成内容草稿 |
| **审核流程** | 草稿 → 待审核 → 已批准 → 已发布 / 已拒绝 |
| **多平台分发** | 公众号、企微、抖音、小红书、快手、B站、微博 |
| **定时发布** | 支持指定时间自动发布 |

### 2.5 智能调度 (Scheduler)

**功能**: Cron 定时任务 + Hermes Agent 自动化执行。

| 功能 | 描述 |
|------|------|
| **定时任务** | 支持 cron 表达式，精确到分钟级 |
| **脚本注入** | Python 脚本在 Agent 运行前执行，输出注入上下文 |
| **自动执行** | Hermes Agent 解析任务描述，自动调用工具完成 |
| **执行历史** | 完整的执行记录和状态追踪 |
| **启停控制** | 支持暂停/恢复/手动触发 |

### 2.6 智能评论 (Smart Comment)

**功能**: 自动化评论互动 + 意向识别 + 线索转化。

| 功能 | 描述 |
|------|------|
| **AI 评论生成** | LLM 根据目标内容和人格设定自动生成评论 |
| **多轮互动** | 支持持续监控和回复 |
| **人格设定** | 自定义评论语气和风格 |
| **意向识别** | 高价值回复自动识别、评分、创建线索 |
| **风控** | 冷却时间、日上限、连续失败熔断 |

### 2.7 AI 智能体 (Agents)

**功能**: 12 个预设 SME 场景 AI 专家。

| Agent | 场景 | 能力 |
|------|------|------|
| 通用助手 | 日常办公 | 问答、写作、分析 |
| 招聘面试官 | HR | JD 生成、面试题设计、候选人评估 |
| 营销文案师 | 营销 | 短视频脚本、公众号文章、产品描述 |
| 视频脚本生成器 | 媒体 | 分镜脚本、旁白、字幕建议 |
| SEO 优化顾问 | 营销 | 关键词研究、本地搜索优化 |
| 经营分析师 | 商业 | 营收分析、成本结构、利润诊断 |
| 智能客服 | 客服 | 7×24 多轮对话、知识库检索 |
| 专业翻译官 | 通用 | 15 种语言商务翻译 |
| 法律助手 | 合规 | 合同审查、劳动法咨询 |
| 商业文档助手 | 办公 | 商业计划书、项目方案、工作总结 |
| 客户跟进管家 | 销售 | CRM、跟进话术、复购激活 |
| 门店运营顾问 | 零售 | 选址、陈列、促销、排班 |
| **销冠助手** 🆕 | 销售 | 话术生成、异议处理、成交信号识别 |

### 2.8 知识库 (Knowledge)

**功能**: 企业文档管理 + FTS5 全文检索 + RAG。

| 功能 | 描述 |
|------|------|
| **文档摄入** | 支持文本格式导入 |
| **全文检索** | SQLite FTS5 引擎，秒级搜索 |
| **向量检索** | 火山引擎 Embedding Vision 多模态向量 |
| **AI 检索** | Hermes Agent 自动检索相关知识回答问题 |

### 2.9 品牌管理 (OEM)

**功能**: 白标定制 + 多主题。

| 功能 | 描述 |
|------|------|
| **品牌定制** | 系统名称、Logo、版权声明自定义 |
| **5 套主题** | 经典蓝、暗夜黑、自然绿、日落橙、星空紫 |
| **免责声明** | 可配置页面展示 |

### 2.10 AI 图像/视频

| 功能 | 描述 |
|------|------|
| **AI 图像生成** | ComfyUI 本地 SD 2.1 + 火山引擎 Seedream 5.0 |

## 三、典型用户场景

### 场景 1：发现高意向客户 → 自动跟进

```
1. 运营人员在智能评论中配置监控任务
   → 系统自动在抖音/小红书评论区发布互动评论
2. 用户回复"这个多少钱？怎么买？"
   → AI 自动评分: 0.88 分，高意向
   → 自动创建线索到线索管家
3. 销售人员打开线索管家
   → 看到高意向线索 + AI 建议话术
   → 点击进入详情，复制话术发送给客户
4. 3 天后，系统自动提醒跟进未回复客户
```

### 场景 2：AI 超级员工 — 一句话完成运营任务

```
用户: "帮我看看今天有什么要做的"

超级员工:
  🔧 调用 lead_stats() → 6 条线索，1 条高意向
  🔧 调用 sched_list() → 3 个待执行任务
  🔧 调用 pub_list(status="pending") → 2 篇待审核
  
  📊 今日待办:
  1. 🔥 高意向线索「测试客户」需要跟进
  2. ⚡ 2 个定时任务待执行
  3. 📝 2 篇内容需要审核
  
  需要我帮你处理哪一个？
```

### 场景 3：内容创作 → 审核 → 发布

```
1. 运营人员打开内容发布，点击「AI 创作」
   → 输入主题"618大促活动方案"
   → AI 生成完整的推广文案
2. 提交审核 → 管理员审批通过
3. 设置定时发布: 明早 10:00 发布到公众号 + 抖音 + 小红书
4. 到时间自动发布
```

### 场景 4：OEM 贴牌 → 分发给代理商

```
1. OEM 客户登录管理后台
   → 上传自己的 Logo
   → 选择「日落橙」主题
   → 设置版权信息「© 2024 XX科技」
2. 系统自动保存，所有页面即刻生效
3. 代理商获得独立品牌形象的运营系统
```
