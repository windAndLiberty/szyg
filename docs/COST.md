## 生产环境成本预估

基于典型中小企业的使用场景：

| 场景 | 日调用量 | 单次 tokens | 日消耗 | 月消耗 |
|------|----------|-------------|--------|--------|

| 智能评论 (Comment) | 200 次/天 | ~150 | 30,000 | 900,000 |
| 文案生成 (Copy Gen) | 50 次/天 | ~300 | 15,000 | 450,000 |
| 意向评分 (Lead) | 100 次/天 | ~100 | 10,000 | 300,000 |
| 图像生成 (Image) | 10 次/天 | — | — | ~10 元 |
| **合计** | | | **~75,000/天** | **~225 万/月** |

### 成本分析

| 方案 | 月费用 |
|------|--------|
| **免费额度内**（日均 < 500 次调用） | **0 元** |
| 超免费额度后按量付费（DeepSeek V4 Flash ¥1/M tokens） | ~¥2.25/月 |
| 超免费额度后按量付费（DeepSeek V4 Pro ¥2/M tokens） | ~¥4.50/月 |
| 图像 10 次/天 (Seedream 5.0) | ~¥10/月 |

**结论**: 免费额度（50 万 tokens/天）足够覆盖中小企业的日常运营需求，月成本预计 **0-15 元**。

## 推荐生产配置

```yaml
# 日常任务 → deepseek-v4-flash-260425 (便宜、快)
# 复杂推理 → deepseek-v4-pro-260425   (高质量)
# 图像生成 → doubao-seedream-5-0-260128
# 视频生成 → doubao-seedance-2-0-260128 (按需使用)
```

### 成本优化建议

1. 默认使用 Flash 模型（¥1/M tokens），仅复杂任务用 Pro
2. 设置日调用上限防止意外消耗
3. 缓存常见回复减少重复调用
4. 图像/视频按需生成，批量任务合并处理
